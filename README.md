# TMP Admin / PM Portal — Prototype

A static HTML prototype for the Trade Modernisation Project's internal Admin/PM Portal. It serves as a visual and interactive reference for stakeholder review, demonstrating the intended UI, layout, and core workflows before full development begins. The prototype covers staff request management (travel, DTA, hardware/software, expenses, HMO), departmental report uploads, an approvals queue, and an AI assistant interface for querying portal data.
